# 第1行 = 桥地址（PC 端 res-bridge.py 的地址，PC 必须和 Kindle 在同一局域网）。
#
#   怎么填：
#     同一路由器下 → 填 PC 的 IPv4 地址（Linux: ip a / Windows: ipconfig）
#     PC 开热点给 Kindle → 填热点的网关地址，常见是 192.168.137.1
#
#   ⚠️ 同一 WiFi 下的 IP 是 DHCP 动态分配的，重连 / 休眠唤醒 / 路由器重启后可能变；
#      变了就重新查 IP、改这里、然后重新部署插件。
#
# 可选配置（不写就用默认值；一旦在插件菜单里改过桥地址，以菜单为准）：
#
#   theme=dark    黑底白字（默认）
#   theme=light   白底黑字 —— 墨水屏白天反光时更好读
#
#   host=vm2      监控「另一台机器」：那台机器上跑 res_report.py 往桥里推
#                 自己的数据，Kindle 看板就跟随那台机器（名称=它的 hostname
#                 或 agent --host 指定值）。不写 = 监控桥所在机器本身。
#
# 退出常驻看板：点屏幕任意处 / 长按 / 滑动 / 上下翻页键 / 菜单里的 ✕
#
# 想用手势打开：设置 → 手势 → 添加手势 → 画一个手势 → 动作列表里选
#   「Host 常驻看板」      （再滑一次就退出，等于开关）
#   「Host 退出常驻看板」  （只退出）
#   「Host 设置休眠壁纸」  （锁屏显示最新看板图）
# 装完插件重启一次 KOReader，动作才会出现在列表里。
#
# 渲染全部在 PC 端完成，Kindle 只取一张 8 位灰度 PNG；
# 文字板仅在图片下载失败且无缓存时自动兜底。
